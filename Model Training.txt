NEUROAI - MODEL TRAINING
========================

OVERVIEW
--------
The CNN models used in NeuroAI were independently trained using Google
Colab notebooks and then integrated into the final Gradio application.

The training notebooks contain the model development, data preprocessing,
training, validation, and evaluation workflow. The main repository
contains the resulting trained model weights and the deployed inference
application.

MODEL INTEGRATION
-----------------

After training and evaluation, the trained CNN models were saved as
PyTorch .pth files and integrated into the NeuroAI Gradio application.

The application loads the trained model weights and performs inference
on user-provided brain images through the web interface.

IMPORTANT NOTE
--------------

NeuroAI is an educational and research-oriented project. The predictions
generated by the models should not be considered medical advice, diagnosis,
or treatment recommendations.

The models are intended for experimentation and demonstration of
deep-learning-based medical image classification.
